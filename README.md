
# Spotify Clone – HTML & CSS 🎧

A static recreation of Spotify's web interface, built entirely from scratch using HTML and CSS. This project was developed to test my understanding of frontend development fundamentals, particularly website structure, CSS styling, layouts, and visual design.

Every section of the interface was manually structured and styled without using any frontend frameworks, UI libraries, or pre-built templates.

## 🚀 Live Demo

[View Spotify Clone](https://spotify-clone-baisc.vercel.app)

## ✨ Features

- Spotify-inspired user interface
- Navigation bar and search bar layout
- Music library sidebar
- Trending songs and popular artists sections
- Custom cards, buttons, icons, and styling
- Gradient promotional banner
- Vercel Web Analytics integration
- Built from scratch using core web technologies

## 🧠 Development Approach

Rather than directly starting with the code, I followed a structured, section-by-section approach to recreate the interface.

### 1. Analysing the Original Interface

I first observed Spotify's original website to understand its layout, visual hierarchy, spacing, alignment, and individual components.

### 2. Planning the HTML Structure

Before implementing the design, I broke down the interface into smaller sections and planned the required div containers, parent-child relationships, and nested elements.

### 3. Building Individual Sections

I developed each section independently, starting with the navigation bar, followed by the sidebar, main content area, music cards, and bottom promotional banner.

### 4. Applying and Revising CSS Concepts

As the project progressed, I continuously applied and revised CSS concepts such as:

- Flexbox and element alignment
- CSS Box Model
- Margin, padding, and spacing
- Positioning and overflow
- Typography and colour schemes
- Backgrounds and gradients
- Selectors and hover effects

### 5. Refinement and Deployment

After completing the overall structure, I refined the styling and layout, fixed visual inconsistencies, and deployed the website using Vercel.

## ⚠️ Current Limitations

- The website is designed primarily for desktop screens and is not responsive.
- It is a static UI clone, not a functional music streaming application.
- Music playback, authentication, and backend functionality are not implemented.

## 🎯 Project Purpose

The primary objective of this project was to evaluate and strengthen my understanding of HTML and CSS before moving towards JavaScript and advanced frontend development.

The focus was not just on recreating an existing interface, but on understanding how complex website layouts can be planned, structured, and implemented using fundamental web technologies.
